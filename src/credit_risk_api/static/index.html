    Explanation

    The free server sleeps when idle, so the first request can take up to a minute. The model was trained on public Kaggle data; its estimates support, rather than replace, a human decision.

    How it works

    Every estimate on this page goes through the same four steps as any other client of the API.

    1. Validate

      The request is checked against a strict schema before it reaches the model. Unknown categories and out-of-range values get a clear error instead of a meaningless prediction.

    2. Predict

      A LightGBM model trained on 300,000 Home Credit applications estimates the probability of default from 11 features.

    3. Explain

      SHAP values give each feature’s contribution to this estimate, computed natively by LightGBM.

    4. Narrate

      On request, an LLM turns the contributions into a short paragraph and relates it to excerpts of the EBA guidelines on loan origination.

    Tested on every change

    An automated test suite and a Docker build run in GitHub Actions on every push.

    Deployed only when green

    The Docker image goes live on Render only after the checks pass, with one-click rollback.

    Monitored for drift

    Each prediction is logged as JSON, and the Population Stability Index flags when applicants stop resembling the training data.

    Decisions worth a look

    Sensitive attributes left out

    Gender, age, family status and region are excluded from the model, at a cost of about 0.005 AUC. The exclusions are part of the model’s metadata and enforced by a test.

    Facts computed in code, not by the LLM

    Early explanations invented a currency and called a mid-range score “very good”. Now the code labels every factor, and each answer is checked for value judgements before it is returned.

    Retrieval checked by hand

    The first index cited rules on ship financing for consumer loans. Restricting it to the guidelines on loan origination and rewording the searches fixed it.

    Every design decision, its trade-offs and its limitations are documented in the repository.
